# Nexum

**Plataforma web de aprendizaje autónomo**

Nexum es una plataforma diseñada para facilitar el aprendizaje autónomo de manera organizada, interactiva y accesible.

---

## Tecnologías

| Área          | Tecnología          |
|---------------|---------------------|
| Frontend      | Angular             |
| Backend       | Spring Boot (Java)  |
| Base de datos | PostgreSQL          |
| Otros         | Node.js             |

---

## Estructura del equipo y ramas

El proyecto se organiza con las siguientes ramas:

| Persona   | Área     | Rama                        |
|-----------|----------|-----------------------------|
| Carlos    | Frontend | `feature/front-carlos`      |
| Lunita    | Frontend | `feature/front-lunita`      |
| Yoshi     | Backend  | `feature/back-yoshi`        |
| Alex      | Backend  | `feature/back-alex`         |
| Maria     | BD       | `feature/bd-maria`          |
| Akemi     | BD       | `feature/bd-akemi`          |

**Ramas principales:**
- `main` → versión estable
- `develop` → integración del equipo
